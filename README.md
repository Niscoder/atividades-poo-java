# Atividades de Programação Orientada a Objetos (Java)

Atividades desenvolvidas nas aulas de POO. Cada pacote em `src/` é uma atividade independente, com sua própria classe `Main` (ou `Principal`).

| Pacote | Tema | Classes principais |
|---|---|---|
| `Aula05_08` | Classes, construtor e `toString` | `Produto` |
| `AT_02` | Herança e classes abstratas | `Entrega`, `EntregaLocal`, `EntregaNacional` |
| `AT_03` | Herança e polimorfismo | `Personagem`, `Guerreiro`, `Mago` |
| `AT_06` | Interfaces | `Conectavel`, `Impressora`, `CaixaDeSom` |
| `AT_07` | Herança + interfaces | `Funcionario`, `Professor`, `Secretario`, `Registravel` |
| `AT_09` | Classes abstratas + interfaces | `Curso`, `CursoOnline`, `CursoPresencial`, `Certificavel` |
| `AT_10` | Classes abstratas + interfaces | `Entrega`, `EntregaBicicleta`, `EntregaCaminhao`, `Rastreavel` |
| `AT_11` | Herança, casting e interfaces | `Veiculo`, `Carro`, `Moto`, `Operavel` |
| `AT_12` | Entrada com `Scanner` e validação | `Aluno` |
| `AT_13` | Tratamento de exceções e exceção personalizada | `ContaBancaria`, `SaldoInsuficienteException` |
| `AT_15` | Classes abstratas + interfaces | `MaterialBiblioteca`, `Livro`, `Emprestavel` |
| `AT_17` | Arrays simples: cadastro, resumo e busca de notas | `Main` |
| `AT_18` | Enumerações (`enum`): switch, construtor e estado | `CorSemaforo`, `PrioridadeChamado`, `SituacaoLivro`, `Livro` |

## Como executar

Abra o projeto no IntelliJ IDEA e rode a classe `Main` do pacote desejado.
